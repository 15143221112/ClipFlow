# xh-distiller 产品对标分析与路线图

> 版本：v1 · 更新：2026-10-12
> 定位：多平台视频下载 → ASR 转写 → LLM 纠错 → 飞书多维表 → SQLite 入库的一体化知识采集工具

---

## 1. 现状快照

| 维度 | 现状 |
|---|---|
| 下载引擎 | F2（抖音/TikTok/微博/Twitter）+ yt-dlp（YouTube/B站/TikTok/微博/X/IG/通用）双引擎 |
| 转写 | faster-whisper 本地（large-v3-turbo） |
| 纠错 | LLM 补标点 + 领域术语纠错（可配置提示词，任意行业通用） |
| 存储 | SQLite（videos 表，608 条），发布/操作时间、来源、状态、转写全文 |
| 输出 | 飞书多维表 upsert + CSV 导出 + 本地视频/音频/逐字稿 |
| UI | Web 4 Tab（直接下载 / 主页批量 / 历史查询 / 设置），手机响应式卡片布局 |
| 交付 | Docker + systemd，多语言 README，CI/单测 |

## 3. 高分项目的共性长处（可直接借鉴）

综合 yt-dlp、whisper.cpp、Douyin_TikTok_Download_API 等高分项目：

1. **单一清晰核心价值** —— "一个命令/入口下载一切"，README 前 10 秒讲清能干什么。
2. **极简 CLI + 富文档** —— 脚本、CI、定时任务都能调，不是只有 GUI。
3. **活跃维护 + Issue/PR 模板** —— 社区感，Contributing、license、行为准则齐全。
4. **测试 + CI 全覆盖** —— 每个 commit 自动跑单测、lint、构建。
5. **可视化 Demo**（截图/GIF/在线试用）—— 用户第一眼信任的来源。
6. **插件/配置化** —— 引擎、模型、API 均可配置替换，不锁死单一路径。

## 4. 差异化卖点（你的护城河）

| 卖点 | 说明 | 竞品对比 |
|---|---|---|
| **飞书多维表深度集成** | 转写结果 upsert 到飞书表格，形成结构化知识库 | 大多数同类只导出本地文件 |
| **LLM 领域术语纠错** | 提示词可配置，任意行业术语自动纠错 + 加标点断句 | 通用工具不纠领域错字 |
| **F2 + yt-dlp 双引擎多平台** | 一个入口覆盖 10+ 平台，引擎×平台联动 | 单引擎项目做不到 |

## 5. 试用地址方案

服务在内网，需公网暴露才能给他人试用。**前提：先加登录鉴权**（否则转写内容裸奔）。

### 方案对比

| 方案 | 免费 | 稳定性 | 域名 | 适合 |
|---|---|---|---|---|
| **Cloudflare Tunnel**（cloudflared） | ✅ | 高 | 自定义/免费随机 | ✅推荐 |
| **cpolar** | 部分 | 中 | 免费随机，弹验证 | 临时演示 |
| **frp + 公网 VPS** | 需自购 VPS | 高 | 自定义 | 长期生产 |

### 建议路径

1. 先加**密码登录**（环境变量配置，FastAPI 中间件）
2. 用 **Cloudflare Tunnel** 起一个稳定 demo URL
3. 登录墙就绪后再公开给他人试用

## 7. 长期愿景

**从"视频下载工具"进化为"知识采集引擎"**：
输入任意平台的视频/口播 → 自动转写 → 领域纠错 → 结构化入库（本地 + 飞书）→ 全文检索 → 一键导出/同步。让每一个创作者、研究者、行业从业者都能把"刷到的内容"沉淀成"可检索的知识库"。
